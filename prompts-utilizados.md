# Engenharia de Prompts Aplicada aos Estudos 🤖

## 📌 Sobre a atividade

Este arquivo reúne exemplos de prompts para estudar Inteligência Artificial, Python, SQL e desenvolvimento de projetos.

O objetivo é aprender a formular instruções claras para ferramentas de IA e avaliar a qualidade das respostas.

## 🐍 Exemplo 1 — Python

**Objetivo:** Aprender estruturas condicionais.

**Prompt para testar:**

Atue como professor de Python. Explique o funcionamento de if, elif e else com exemplos práticos. Depois, proponha três exercícios para que eu possa praticar.

**Resultado:** Aguardando teste e avaliação.

## 🗄️ Exemplo 2 — SQL

**Objetivo:** Aprimorar conhecimentos em banco de dados.

**Prompt para testar:**

Atue como especialista em SQL. Crie exercícios envolvendo SELECT, WHERE, GROUP BY e JOIN, explicando como cada comando funciona.

**Resultado:** Aguardando teste e avaliação.

## 👗 Exemplo 3 — Projeto Meu Closet

**Objetivo:** Planejar uma aplicação de organização de roupas.

**Prompt para testar:**

Atue como desenvolvedor Python. Ajude-me a estruturar um aplicativo Streamlit que permita cadastrar roupas por imagens, organizar categorias e sugerir combinações de looks.

**Resultado:** Aguardando teste e avaliação.

## 📈 Próximas etapas

- Executar os prompts.
- Registrar as respostas obtidas.
- Identificar melhorias.
- Documentar os aprendizados.
